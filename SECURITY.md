# Security Policy

## Supported versions

Security fixes are currently targeted at the latest published release and the `main` branch.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If private reporting is not enabled, contact the repository maintainers privately through the contact method listed on the GitHub profile.

Do not include passwords, Steam Guard codes, session tokens, account cookies, or other secrets in reports or logs.
