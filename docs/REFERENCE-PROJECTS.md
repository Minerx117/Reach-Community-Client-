# Reference projects and inspiration

## Project Noble — reference only

Project Noble was reviewed only to understand the intended feature set and user experience for a Halo: Reach community client: loading the original menu, browsing servers, hosting/joining sessions, and eventually running dedicated servers. It is **not** part of Reach Community Client.

RCC does not include, copy, link, build, download, launch, or depend on Project Noble source code, binaries, tools, libraries, server directory, or runtime. There is no integration button or build script.

All RCC runtime, UI, multiplayer, and server components must be independently designed, implemented, tested, and contributed in this repository. Looking at publicly visible product behaviour does not make its implementation part of RCC.
